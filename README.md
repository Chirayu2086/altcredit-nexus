**Privacy-First AI Credit Scoring for New-to-Credit Individuals & MSMEs**

Built with **Graph Neural Networks**, **Account Aggregator (AA)** framework, and **Federated Learning** — unlocking credit access for 350M+ underserved Indians.

---

## 🎯 The Problem
- **350 Million+** Indians lack traditional credit history
- MSME credit gap exceeds **₹30 lakh crore**
- Existing systems are slow, biased, and privacy-invasive

**AltCredit Nexus** solves this using alternative data (UPI, GST, utility, telecom) while keeping user data private.

---

## ✨ Key Features

- **Real-time Credit Scoring** (300-900 scale)
- **Explainable AI** with SHAP-style insights
- **Interactive Transaction Graph** visualization
- **AA Consent Flow** simulation
- **Federated Learning** ready architecture
- **Beautiful, Responsive Dashboard**
